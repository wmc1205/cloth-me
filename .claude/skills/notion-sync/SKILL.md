# Notion 일정 동기화

> 사전 조건: Notion MCP가 연결되어 있어야 한다. 연결되지 않았으면 갱신하지 말고 사용자에게 알린다.

## 상태 흐름
`할 일` → `진행 중` → `리뷰 중(PR)` → `완료`

## 절차

### 작업 시작할 때
1. 해당 티켓을 찾는다. (사용자가 말한 이름 또는 `CLAUDE.md`의 MVP 단계 번호)
2. 상태를 `진행 중`으로 바꾼다.
3. 티켓에 브랜치 이름을 적는다. (`feature/...`)

### PR을 올린 뒤
1. 상태를 `리뷰 중`으로 바꾼다.
2. PR 링크와 Vercel Preview 링크를 티켓에 붙인다.

### 머지 후
1. 상태를 `완료`로 바꾼다.
2. 완료일과 간단한 결과(한 줄)를 적는다.
3. 후속 작업이 생겼으면 새 티켓으로 만든다. (스스로 범위를 넓히지 않는다)

## 규칙
- 티켓을 **삭제하지 않는다**. 필요 없어진 작업은 `보류` 상태로 둔다.
- 티켓 제목/설명을 임의로 크게 바꾸지 않는다. 바꿀 때는 사용자에게 먼저 확인한다.
- 티켓을 찾을 수 없으면 새로 만들지 말고 사용자에게 물어본다.
- Notion 토큰이나 페이지 ID를 코드/커밋에 남기지 않는다.
